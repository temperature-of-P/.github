# P의 온도 (Temperature Of P)

> "계획보다 경험, 여행의 우연을 즐기다"
> 계획에 지친 사람들을 위해 여행의 우연과 재미를 게임처럼 경험하게 만드는 랜덤 여행 미션 플랫폼

## 🗺️ 사용자 플로우

```
1. 로그인 (카카오 / 구글 / 애플)
↓
2. 여행 생성 (지역 / 일정 입력)
↓
3. 여행 스타일 선택
   - 완전 랜덤
   - 반랜덤
   - 직접 선택 혼합
↓
4. 일정 생성
↓
5. 첫 목적지 이동
↓
6. 인증샷 업로드
↓
7. 미션 성공 여부 확인 (시간 + GPS + 장소 검증)
↓
8. 다음 랜덤 장소 추천 (후보 3개)
↓
9. 여행 종료 후 결과 분석
↓
10. P 온도 및 랭킹 반영
↓
11. SNS 공유
```

---

## 🎯 핵심 미션 시스템

```
여행지 도착
→ 인증샷 업로드
→ 시간 / GPS / 장소 검증
→ 미션 성공
→ 다음 카테고리 랜덤 뽑기 (관광지 / 식당 / 카페 / 야시장 / 체험 공간)
→ 목적지 후보 3개 제공
→ 사용자 선택 후 이동
→ 반복
```

| 온도 | 의미 |
|------|------|
| 20°C | 여행 초보 |
| 50°C | 활동적인 여행자 |
| 80°C | 랜덤 여행 마스터 |
| 100°C | 전설 등급 |
